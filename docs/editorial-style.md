# 自然中文科普文风规范

本规范约束产品页的中文科普层。目标是准确、自然、克制：读者应先认出具体产品，再理解其适应症和作用机制。审计工具只发现高风险写法，不代替医学审校和来源核对。

## 产品是完整的公开内容单元

公开信息架构固定为“公司 → 产品”。每条新记录只能对应一个具体产品 / 商品名，并在同一页独立说明药物通用名或活性成分、产品适应症和该产品语境下的完整机制。不得把不同公司的品牌、同成分的不同剂型或用途不同的产品合并成一条记录。

成分、靶点和通路只用于组织内部事实与素材，不作为把多个产品文案自动拼成一个页面的依据：

- 相同靶点只允许复用中性的靶点、器官或通路底图；具体分子作用必须逐产品撰写。
- 相同活性成分只有在作用方式、给药途径、主要作用部位、释放方式、复方组成和适应症语境均不改变该事实时，才可复用相应机制片段。
- 复方产品可以复用各成分的基础素材，但整体作用过程必须按该产品重新编写，不能简单拼接单方说明。
- 每次引用共享动画或机制片段都视为一次产品级编辑决定；共享素材更新后，依赖页面必须重新复核，不能静默自动更新。

## 非比较边界

本站解释每个产品自身的事实，不提供横向选药工具。公开文案不得使用“优于、劣于、更安全、更适合、比单用更全面、可替代”或“与另一产品不同”等比较性结论；不得制作疗效、安全性、起效时间、价格、适用人群或替代关系对照表。需要体现分子、复方或给药特征时，只正面说明当前产品的事实，不把另一产品作为参照。机制解释也不得推导为个体用药建议。

## 字段分工

| 字段 | 职责 | 不应承载 |
| --- | --- | --- |
| `summary` | 用一至两句交代药物类别、主要作用和核心用途 | 研发史、销量、排名、宣传评价、完整机制链 |
| `target` | 说明靶点是什么，以及该靶点与疾病变化的关系 | 重复药物如何结合、如何抑制的过程 |
| `analogy` | 可缺省。只有在确实降低理解门槛时，使用一个准确且边界清楚的类比 | 多重比喻、拟人化剧情、把不确定关系说成机械动作 |
| `simple` | 按“疾病变化—靶点作用—药物影响”解释因果链 | 研发故事、同类排名、疗效承诺、过多分子细节 |

`analogy` 不是必填项。没有合适类比时，直接省略比勉强写“开关、钥匙、刹车、士兵”更好。组件也不会为缺省的类比渲染空层。

## 语言规则

1. 使用中文全角标点。英文缩写和药物名可以保留，中文句子不用英文逗号、冒号、分号、引号或感叹号。
2. 一句话只承担一段主要因果关系。建议上限：`summary` 64 字、`target` 72 字、`analogy` 72 字、`simple` 90 字；超过后优先拆句，不靠堆叠逗号延长。
3. 不写“精准狙击、神药、革命性、里程碑式、最佳、彻底根治”等宣传性或绝对化表达。
4. 不把癌细胞写成“狡猾、偷偷逃跑”，也不把免疫细胞写成“卫兵清醒后追杀敌人”。直接描述结合、激活、抑制、增殖和信号变化。
5. 一个字段最多使用一组类比。不要在同一段同时出现钥匙、开关、刹车、工厂和补给线。
6. 避免“一种……抑制剂：”“这个药就是……”“简单来说”“值得一提的是”“双管齐下”等模板句。以具体药名或具体疾病事实起句。
7. `summary`、`target`、`analogy`、`simple` 不互相复制。重复事实时，应按字段职责改变信息层级，而不是换几个同义词。

## 来源与原创转述

编辑可从以下权威患者教育或癌症科普页面理解术语、适应证和机制背景；链接是核查入口，不是可直接拼接的文案：

- NCI：https://www.cancer.gov/about-cancer/treatment/drugs/imatinibmesylate
- MedlinePlus：https://medlineplus.gov/druginfo/meds/a606018.html
- Cancer Research UK：https://www.cancerresearchuk.org/about-cancer/treatment/drugs/imatinib
- Memorial Sloan Kettering Cancer Center（MSK）：https://www.mskcc.org/cancer-care/patient-education/medications/adult/imatinib
- Mayo Clinic：https://www.mayoclinic.org/drugs-supplements/imatinib-oral-route/description/drg-20068331
- Cleveland Clinic：https://my.clevelandclinic.org/health/treatments/24984-tyrosine-kinase-inhibitors

原创转述遵循以下原则：

- 先从至少两个来源提取可核验的事实点，再脱离原句组织中文；不得逐句翻译、拼接或只替换同义词。
- 保留事实边界和限定词，不把“可用于”“有助于控制”“抑制生长”改成“治愈”或“消灭”。
- 来源之间有差异时，回到监管说明书或专业指南核实；患者教育页不替代适应证、禁忌证和剂量依据。
- 专有名词、机制关系和适应证属于事实，但来源独有的叙事结构、比喻和措辞不得照搬。
- 每次改稿保留实际使用的引用；编辑规范中的 URL 不能自动充当具体药品页的证据。

## 伊马替尼候选文案

以下文案用于展示字段分工，发布前仍须按当前说明书和适应证复核。

**summary**

伊马替尼是一种靶向药，主要用于某些白血病和胃肠道间质瘤。是否适用，要看肿瘤细胞是否存在 BCR-ABL、KIT 或 PDGFRA 等相关异常。

**target**

以慢性髓性白血病为例，许多患者的白血病细胞会产生异常的 BCR-ABL 蛋白。它会持续推动这些细胞增殖。

**analogy**

建议缺省。这里直接说明“异常蛋白持续推动细胞增殖，药物抑制其活性”更清楚，不需要再套用开关、钥匙或刹车。

**simple**

伊马替尼会抑制 BCR-ABL 蛋白的活性，让推动白血病细胞增殖的信号弱下来。它也能抑制 KIT 和 PDGFRA，因此还可用于部分胃肠道间质瘤等疾病。具体是否适用，需要结合疾病类型和相关检测结果判断。

## 审计方式

- `npm run content:audit`：扫描现有药品内容，输出 JSON；legacy 模式只报告问题，退出码不因文风问题失败。
- `npm run content:audit:strict -- <path>`：检查新稿或指定路径；任何文风问题都会形成阻断性结果并返回非零退出码。

审计脚本只读取 Markdown 并输出 JSON，不会自动改写内容。命中规则表示“需要编辑复核”，不表示医学事实一定错误。
