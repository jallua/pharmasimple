# Security policy

## Supported version

Only the current `main` branch and the production deployment built from it receive security fixes.

## Report a vulnerability

Do not open a public issue. Use GitHub **Security → Advisories → Report a vulnerability** to send a private report. Include the affected commit, reproduction steps, impact, and any suggested mitigation. Do not include real patient or other sensitive data.

The maintainer will acknowledge a report within 3 business days, provide a triage decision within 7 business days, and coordinate disclosure after a fix is deployed. If private vulnerability reporting is not enabled, contact the repository owner through the private contact method listed on their GitHub profile.

## Scope

Reports about dependency compromise, workflow/token exposure, unsafe generated medical content, provenance bypass, and unauthorized deployment are in scope. This site is informational and must not be treated as medical advice.
